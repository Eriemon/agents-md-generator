# Contributing

Thank you for improving AGENTS.md Generator. Before contributing, read the skill instructions, review checklist, and release guidance.

## Development conventions

1. Read the current handoff, AGENTS rules, and graph state before freezing the goal and scope.
2. Before changing Python or scripts, pass both readable-code workflow gates.
3. Keep readable multi-line structure, semantic variable names, and justified comments; do not compress code into one line.
4. Freeze the candidate and run narrow checks first. Long tasks require bounded timeouts plus status, logs, and receipt signals. The canonical TESTER owns the governed test tree and execution.
5. Keep VERSION, the bilingual README, license, security, contribution, metadata, and citation files synchronized.

## GitHub integration

For contributions involving a remote skill repository, register the existing mapping in the project control configuration and follow the governed status, check, release, mirror, plan, confirmation, and verification sequence. Tools update only the current workspace checkout; they do not create remote repositories or replace maintainer push or release actions.

## Pre-submission checks

- README illustrations are local high-resolution PNG files with no SVG, Mermaid, or remote images.
- The release directory matches the source version and contains the release receipt.
- The handoff records the change summary, verification evidence, and remaining risks.
